# NetWeaver Product Spec

## Product
Browser-native AI automation engine that understands DOM, JS runtime, network, visual state, and verification better than generic LLM browser agents.

## First SaaS wedge
Reliable web task automation for developers/ops:
- inspect page
- create world model
- execute verified browser actions
- produce evidence report

## MVP Demo
Natural language request -> WNAL plan -> CloakBrowser observer -> verified action report.

## Differentiator
No claim without browser evidence.

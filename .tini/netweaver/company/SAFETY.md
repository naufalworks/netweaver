# NetWeaver Safety Policy

Require confirmation for:
- payments/purchases
- messages/posts/emails
- deleting/modifying remote data
- account/security changes
- credential submission unless explicitly authorized

Forbidden for autonomous workers:
- secrets/env/auth edits
- git push/deploy
- vendor/CloakBrowser edits
- browser anti-bot bypass beyond lawful automation testing

Allowed:
- local docs/scripts/tests
- browser observation prototypes
- mock tests

# NetWeaver Novelty Thesis

NetWeaver is not an LLM + Playwright wrapper.

## Core Claim
Playwright/CloakBrowser automates browser actions. NetWeaver understands and verifies web state transitions.

## Product Category
Evidence-native web cognition engine / browser-native AI operating system.

## Novel Components

### 1. WebSceneGraph
A unified graph of browser reality:
- DOM graph
- accessibility graph
- visual/layout graph
- network graph
- JS/runtime state graph
- storage/session graph
- user-intent graph

### 2. WNAL/BASIL
A web-native agent language:
- intent
- observation
- typed actions
- preconditions
- expected state transitions
- evidence requirements
- recovery policies

### 3. Evidence-first Verifier
No claim without proof. Success is proven by DOM/network/JS/storage evidence, not model confidence.

### 4. Network-aware Intent
NetWeaver learns frontend-backend causality:
click -> request -> response -> state update -> UI confirmation.

### 5. Site Skill Learning
Successful flows become reusable verified site skills with evidence contracts.

### 6. Perspective Engine
NetWeaver resolves conflicts between user, DOM, visual, network, JS, safety, and history perspectives before acting.

## Anti-Goal
Do not become: LLM writes Playwright scripts.

## Target Behavior
Natural language -> WNAL -> WebSceneGraph -> verified action -> evidence report -> reusable site skill.
